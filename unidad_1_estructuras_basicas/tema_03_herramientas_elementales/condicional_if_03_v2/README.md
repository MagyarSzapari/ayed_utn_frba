## Objetivo académico

Variante de Condicional_if_3 con el operador &lt;=: informa si el número es menor o igual que 5 o mayor que 5.

## Estrategia de resolución

1. Definir dato = 5
2. Leer numero
3. if (numero &lt;= dato) informar menor o igual; else informar mayor

## Estructuras de datos utilizadas

- variables simples int
- operador relacional &lt;=
- decisión simple if-else

## Compilar y ejecutar

```bash
g++ main.cpp -o condicional_if_03_v2
./condicional_if_03_v2
```
