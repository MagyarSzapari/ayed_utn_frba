## Objetivo académico

Ejercita la lectura desde entrada estándar con cin: pide un número entero y uno real y los muestra de vuelta (eco) por salida estándar.

## Estrategia de resolución

1. Mostrar un mensaje pidiendo el dato
2. Leer con cin en una variable int y luego en una float
3. Mostrar cada valor leído

## Estructuras de datos utilizadas

- variables simples int/float
- entrada estándar (cin)
- salida estándar (cout)

## Compilar y ejecutar

```bash
g++ main.cpp -o entrada_de_datos
./entrada_de_datos
```

**Estado:** ✅ compila con g++ 15.1 (MSYS2 UCRT64, dialecto por defecto gnu++17).
