## Objetivo académico

Usa if-else con el operador >= para informar si el número es mayor o igual que 5 o menor que 5, cubriendo correctamente el caso de igualdad.

## Estrategia de resolución

1. Definir dato = 5
2. Leer numero
3. if (numero >= dato) informar mayor o igual; else informar menor

## Estructuras de datos utilizadas

- variables simples int
- operador relacional >=
- decisión simple if-else

## Compilar y ejecutar

```bash
g++ main.cpp -o condicional_if_03
./condicional_if_03
```
