## Objetivo académico

Lee un número real y con una decisión encadenada informa si es cero, positivo o negativo.

## Estrategia de resolución

1. Leer numero (float)
2. if numero == 0 informar cero
3. else if numero > 0 informar positivo
4. else informar negativo

## Estructuras de datos utilizadas

- variables simples float
- operadores relacionales
- decisión encadenada if-else if-else
